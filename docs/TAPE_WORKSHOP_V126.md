# Tape Workshop v126

Based on Melodee by Kerem Kiliç (Ellic Studio).

Final Cut layers and Save Final Cut files are always visible beside the recording controls. Enable layers before starting a take; the save link becomes ready after stopping. Existing recordings without separate layers cannot be converted retroactively.

The live screen drains stale frames even when a browser audio clock is suspended, and refreshes on return from Save As or window focus. Download fallback opens separately to preserve the live page. Tests cover suspended and running audio-clock behavior; hardware/browser verification remains necessary.

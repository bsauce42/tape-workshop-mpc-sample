# Tape Workshop v123

Based on Melodee by Kerem Kiliç (Ellic Studio).

The MPC stays upright; angle choices have been removed. Tutorial Mode now has independent MPC and large-screen camera framing, available through Framing beside Both / MPC only / Screen only. Each camera has 1×–4× zoom, horizontal and vertical pan. Drag a zoomed preview to pan, including touch. Full unit, Knobs and Pads frame common sections; Reset screen restores only the large screen. Camera adjustments ease over 220 ms; composition changes retain the 450 ms transition.

Framing changes work while recording without restarting audio or video. Preview and export use the same crop calculation; the MPC photograph, LCD, knob indicators and pad highlights move together. The framing controls stay available in Clean view but are excluded from exported videos. v122 file-search additions and all 22 plug-ins are retained.

Validation: ARM build, independent crop/proportion/edge-pan tests, and a continuous 40-second 1920×1080 local recording with separate zoom, section presets, reset and drag pan. Hardware testing remains pending.

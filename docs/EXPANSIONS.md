# Tape Workshop Expansions

On a sampler track, hold the encoder to open MENU, choose HERE, then **EXPANSIONS**. The same entry is available from the Sample Select browser.

- **My Packs** opens `Samples/Expansions` on the SD card.
- **Install Pack** opens the card so you can find a `.xpn` expansion. Push or B3 installs its contents into `Samples/Expansions/<title>` and opens that folder. Installation adds library files; it does not load or replace your current kit.
- **Import Bank** browses Samples for an `.mldb` bank file or a drum `.xpm`/`.xty` program. A native bank brings its sixteen pads; a drum program brings the source bank selected with K2. Only the destination bank shown in the header is replaced. Other banks, patterns and track mix remain.
- **Import Pad** loads one pad from a bank/program, with its pad settings, layers and pad effects. Choose the source bank with K2 and source pad with K3. For an `.mldb`, K2 is ignored because it already contains one bank. A WAV, AIFF, FLAC, Ogg or MP3 file can also be loaded onto the last pad selected, using the normal sample-loader behavior.

The wheel or K1 moves through the files. Push or B3 opens folders, installs packs, or loads content. B1 goes up a folder; B2 returns to the four expansion choices. Shift+B3 toggles preview. Pad Bank selects the destination bank; strike a pad to choose a destination for a single-pad import. Check the destination in the header before loading. Bank/pad replacement has an undo step. Empty source banks/pads do not erase anything. Imports stop if there are not enough sample slots, the project changes, the track changes type, or recording starts while a program is being read.

To get a pack onto the card, use the companion site's Files upload or copy it from your computer. Expansion Builder `.xpn` files are supported. Encrypted/protected commercial expansion formats and desktop instrument plug-ins are not imported. The OS expansion browser shows the pack cover, title and maker beside the file list. It reads Expansion.xml image metadata (including the web builder's Artwork.jpg) and searches inside the selected pack. Supported JPEG/PNG artwork is capped at 4 MB and 2048 x 2048 pixels, then reduced to a 128-pixel thumbnail on the service thread. Missing or invalid artwork leaves the normal list usable. Artwork paths cannot leave the pack folder.

Before installing a firmware update, save your project. Physical-device checks of this new screen are still pending.

Tape Workshop is based on Melodee by **Kerem Kiliç (Ellic Studio)**; the underlying sample browser and pack readers originate there.

## Compatibility checked in v90

A pack generated by the production web builder was installed using the production ExpansionInstall reader, then loaded through the drum-program importer. The test verified the JPEG cover, title/maker, three assigned pads with non-silent WAV data, destination-bank loading and individual-pad loading, preserving other pads. A synthetic MPC 3 gzip JSON .xty fixture with its _[TrackData] folder passed the same bank/pad import and cover checks. This is format compatibility testing, not a real MPC 3 Desktop export or a physical MPC playback test. A genuine export from the user is still needed for that final confirmation.

The matching native integration probe is tests/expansion_compat.cpp; tests/generate_expansion_fixture.js generates its fixtures with the actual web builder. The existing tests/expansion_core.js checks artwork inclusion and XML metadata. Physical MPC checks remain pending.

## Export directly to the MPC (v93+)

In the companion Expansion Builder, **Save to MPC** writes the generated `.xpn` archive, including pad samples and artwork, into the SD card’s top-level `Expansion Packs` folder. The folder is created when needed. An existing pack is preserved by choosing a new filename. **Download a copy** still saves to your phone or computer. Saving requires the browser to be connected to the MPC with its SD card available; success appears only after the MPC confirms the save.

To use the saved archive, open the OS EXPANSIONS menu, choose **Install Pack**, and open `Expansion Packs`. Installed library contents remain in `Samples/Expansions`; saving an archive does not replace the current kit or automatically install it.

## Import Pad from the new-track menu (v94+)

On an empty track, turn the encoder through **Drum, Keygroup, Plugin, MIDI, Audio, Import Pad** and push **Import Pad**. Choose **From Pack** to create a drum track and open the single-pad expansion browser, or **Empty Pad** to create a blank drum track without loading a sample. Choose a bank/program and use K2/K3 for its source bank/pad, or choose a WAV. After a successful import, return to the page where you selected the empty track. B1 back to the expansion home, then B1 cancel removes the still-empty new drum track. The existing Expansions menu shortcut remains available for importing into an already-used drum track.

## Audition builder pads (v95+)

Tap or click an assigned pad to select it and audition its sound through the phone/computer. Keyboard Enter/Space works on a focused pad. Empty pads select silently. **Stop sounds** stops all previews, and preview voices are bounded to 16.

Tap **Enable MPC pads** to use the physical MPC pads as triggers for the browser’s current expansion bank. This uses the connected Tape Workshop surface feed, without Web MIDI permissions, and requires v95+. Keep the builder visible. Disabling it or leaving the page stops the polling; hiding the page pauses polling and stops preview audio. Reconnecting seeds a fresh state rather than replaying old hits. Network preview has latency and is intended for auditioning; multiple strikes within a single poll are coalesced.

These previews play on your phone/computer, not the MPC outputs. The physical pads still operate the selected MPC track normally; select an empty drum track to avoid also hearing the current kit. To play the finished sounds through MPC outputs, save/install the expansion and load its bank.

## Eight-bank builder (v96+)

The Expansion Builder holds 128 sample slots in banks A–H, with sixteen pads per bank. Bank buttons switch the visible grid without losing assignments. Multi-file import fills from the selected pad into following banks, wrapping H16 to A01. The 250 MB total sample limit remains shared across the whole pack. Exports include every assigned pad in a single drum program; empty slots stay empty. MPC physical pad preview follows the bank selected in the browser.

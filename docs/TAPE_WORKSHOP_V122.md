# Tape Workshop v122

Based on Melodee by Kerem Kiliç (Ellic Studio).

## File search

Hold Shift and press B1 in Open Project, plug-in browser, plug-in presets, MIDI Import, expansion file browser, or the sample-folder picker. Type with the pad keyboard; results update from the first letter. Partial words and phrases match without case sensitivity. Names beginning with the first typed word appear before matches later in a name. B3 Done or B1 Back closes typing and keeps the filter; B1 Clear returns the full list. Opening a folder clears its previous filter. These pickers search the current folder; Sample Select retains its existing indexed sample search. Loading, previewing, importing, and deleting use the filtered file identities.

## Tutorial presentation

Screen frame offers Plain or Tablet on Live Screen and Tutorial Mode. Tutorial Mode also offers Front, Left angle, and Right angle views for every device style. These are presentation tilts of the existing image, keeping the LCD and hardware indicators together. Preferences stay on the browser. Recorded exports include the same frame and tilt. Full HD and 720p recording remain available.

Validated by native ARM build, search ordering and identity tests, presentation matrix tests, and a continuous 25-second 1920×1080 local recording switched through all three layouts using a demo screen and synthetic audio. On-device SD navigation and recording still require hardware testing.

During a live recording, use Both, MPC only, or Screen only to switch compositions. The preview and saved video use the same 450 ms eased zoom/fade, without restarting the recorder or audio. The switcher remains available in Clean recording view and is excluded from the exported video.
